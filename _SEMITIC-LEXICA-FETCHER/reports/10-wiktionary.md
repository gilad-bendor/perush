## Access class and what the tool does

`wiktionary-semitic` → **open**. `cli fetch wiktionary-semitic` (or `cli wiktionary`): MediaWiki API `list=categorymembers` (500/page, continued) → `prop=revisions&rvslots=main` in batches of 50 → the level-2 language section of each page → `data/wiktionary-semitic/wiktionary/<category>.json` (`{title, language, section}`).

## Value

Cheap, structured, permissively licensed; good for cross-checking transliterations and for the cognate lists in Proto-Semitic pages. Coverage of MSA is thin.
