# Shared renderings: the city laments (the Lament for Ur, the Curse of Agade)

Binding for both projects of this folder (`corpus.md`). Echo tags follow guidelines §6.4: [cognate], [equivalent], [divergence], [absent]. Fixed by the corpus coordinator before the first run (2026-10-19); translators add rows to their project's `renderings.md` and write proposals in `project.md`; the coordinator merges them here between runs (§9).

## 0. Inheritance
1. **The creation corpus's Sumerian renderings bind here as the default**: `../סיפורי-הבריאה-המסופוטמיים/renderings.md` §5–§8 (and its §0, inherited from the flood corpus), and the Sumerian rows of `../סיפורי-הבריאה-המסופוטמיים/2-טקסטי-בריאה-ועדן/renderings.md` and `4-אנקי-וסדר-העולם/renderings.md`. Look a word up there (`python3 -I ../סיפורי-הבריאה-המסופוטמיים/sumerian_tools.py grep all '<regex>'`, or `python3 -I lament_tools.py grep all '<regex>'`, which also searches the creation corpus) before fixing it.
2. **The rule of the law corpus (`../חוקים-ובריתות/renderings.md` §6) applies: a Sumerian word takes the Hebrew of its Akkadian equivalent** (*du₆* = *tīlu* = `תֵּל`; *ad₆* = *pagru* = `פֶּגֶר`; *gur* / *gi₄* = *târu* = `שׁוּב`; *im* = *ṭīdu* = `טִיט`; *nam … ku₅* = *arāru* = `אָרַר`; *a-nir* / Emesal *a-še-er* = *tānīḫu* = `אֲנָחָה`; *lil₂* = *zaqīqu* = `מַשַּׁב`). Then a Sumerian lament and an Akkadian text that share a word read the same in Hebrew.
3. **The wisdom corpus** (`../ספרות-החכמה-והצדיק-הסובל/renderings.md`) is the model for the lament vocabulary of personal religion (*anāḫu* / *tānēḫu* = `נֶאֱנַח` / `אֲנָחָה`; *rēmu* = `רַחֲמִים`; *kabattu* = `כָּבֵד`; *aḫulap* = `רַב!`).
4. **Cross-corpus splits followed here as the creation corpus has them (flagged at first; Inana, *me* and *mušen* settled as here by the 2026-10-21 harmonization, see §9.5; Nisaba still open):** Inana = `אִינַנָּה` (creation corpus; the law corpus writes `אִינַאנָּה`); *me* = `הַ־מֶה` (creation corpus; the flood corpus's Sumerian project renders *me maḫ* `הַכֹּחוֹת הַנִּשְׂגָּבִים`); Nisaba = `נִיסַבָּה` (EWO; the Song of the Hoe has `נִיסָבָּה`); *mušen* = `צִפּוֹר` (creation §6.1; project 2 has `עוֹף` in two places).

## 2. Emesal
Much of the Lament for Ur (Ningal's speeches, the refrains) is in **Emesal**, the "fine tongue" in which Sumerian literature makes goddesses and women speak and in which the *gala* lamentation priests sang. Emesal changes sounds and some words (*ga-ša-an* = *nin* "lady", *mu-lu* = *lu₂* "person", *u₃-mu-un* = *umun/en* "lord", *mu-ul-lil₂* = Enlil, *me-e* = *ĝe₂₆-e* "I", *ka-na-aĝ₂* = *kalam* "land", *na-aĝ₂* = *nam* "fate", *e-ne-eĝ₃* = *inim* "word", *ma-al* = *ĝal₂* "be", *ga* = *de₆* "carry", *-ĝen* = *-me-en* "I am", *nu-nus* = *munus* "woman"). **The Hebrew renders the main-dialect word** (identical meaning = identical Hebrew, whatever the dialect); the **פירוק** bullet names the Emesal form and its main-dialect equivalent; the header of each annotated file explains Emesal; a line's dialect is never marked in the `>` line.

## 5. Reserved strings (never in a `>` line unless the transliteration has the licensing word; checked by `lament_tools.py verify`)

## 6. Traps of unvocalized Hebrew
`אור` (Urim / "light"), `אומה` (Umma / "nation"), `באו` (Bau / "they came"), `אן` (An / "whither"), `אותו` (Utu / "him"), `איננה` (Inana / "is not"), `שומר` (Sumer / "guard"), `כש` (Keš), `שרא` (Šara), `המה` (*me* / "they"): vocalize at every occurrence (the script checks those whose name is in the transliteration). `הושמה` ("was made desolate") – use `שׂוּמָה`; `דגן` (Ezina) – vocalize as a name; `גביר` / `גבירה` – vocalize `גְּבִיר` the first time.
