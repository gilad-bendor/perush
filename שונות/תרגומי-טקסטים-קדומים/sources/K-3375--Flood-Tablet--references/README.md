# K 3375 – the "Flood Tablet" (Gilgamesh SB XI, MS J1) – references only

Checked 2026-10-16. Only URLs are recorded here (no images were downloaded). Other folders in `sources/` (e.g. `CDLI/`, `eBL/`) are maintained by other tasks.

- **Object:** British Museum K 3375 (Kuyunjik/Nineveh, Neo-Assyrian, 7th c. BCE). This is the tablet George Smith recognised in 1872. George's siglum is **J1** (joined in the score with J2 = Rm 616 as "K 3375 + Rm 616"; CDLI also records it as K 03375 + Rm 0616). eBL description: "Fragment of a clay tablet, upper right corner, 2 columns of inscription on either side, 49 and 51 lines + 45 and 49 lines … Epic of Gilgamesh, tablet 11, story of the Flood." It has a photo in eBL.
- **Coverage (George 2007 score):** J1 has XI ii 56–107, iii 110–166, iv 167–229, v 230–84. J2 (Rm 616) has i 1–23.
- **British Museum collection online:** https://www.britishmuseum.org/collection/object/W_K-3375 (BM ID W_K-3375; returns 403 to scripts, so open it in a browser). Images there are typically CC BY-NC-SA 4.0 (BM standard terms).
- **CDLI:** https://cdli.earth/artifacts/273210 = **P273210** ("Gilgamesh II 124ff, J"; no CDLI image as of 2026-10-16).
- **eBL Fragmentarium:** https://www.ebl.lmu.de/library/K.3375 (old path /fragmentarium/K.3375 redirects). API JSON: https://www.ebl.lmu.de/api/fragments/K.3375 (external numbers: cdliNumber P273210, bmIdNumber W_K-3375).
- **Publication:** George, *BGE* II (2003) pls. 124–127 (hand-copy, "Gilgamesh II 124ff, J"). Older copies: Haupt, *Nimrodepos* (1891); Thompson 1930 pls. 44 ff.; IV R² 43–44 (Pinches 1891); Smith, TSBA 2 (1873).
