# ORACC ETCSRI Q000377 — The building of Ninĝirsu's temple: the ETCSRI translation

- **What:** the English translation of the Gudea Cylinders in the *Electronic Text Corpus of Sumerian Royal Inscriptions* (Zólyomi, Tanos, Sövegjártó, 2008–; Budapest, ELTE), extracted from the per-text HTML view. It follows Edzard 1997 (RIME 3/1) with revisions. 111 units labelled with the line where each starts (`Cylinder A i 1`). **Partial**: it has no units for A xxiv 26 – A xxx 13 and B xiii 1 – B xvii 17 (the HTML gives the transliteration there without translation).
- **URL:** https://oracc.museum.upenn.edu/etcsri/Q000377/html (retrieved 2026-10-20; `curl --max-time 60`).
- **Licence:** "The ETCSRI Project at Oracc.org / Content released under a CC BY-SA 3.0 licence" (project pages). The `.md` is committed with this attribution; the raw HTML (2.5 MB) is gitignored.
- **Files:** `Q000377--etcsri.html` (raw, gitignored), `Q000377--etcsri-translation.md` (`tools/oracc_html2tr.py`; non-breaking spaces normalised).
- **Usefulness:** rank 3 – the second modern translation after ETCSL's; based on the current edition (Edzard 1997). Consult after your own reading.
