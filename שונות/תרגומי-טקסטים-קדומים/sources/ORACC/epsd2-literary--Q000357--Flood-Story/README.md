# ORACC epsd2/literary — The Flood Story (Q000357) and its Ur manuscript (P346146)

- **Editors:** ePSD2 / ORACC (S. Tinney et al.), composite derived from ETCSL 1.7.4 (Black, Cunningham et al., after Civil 1969 and Jacobsen 1981); P346146 transliteration after J. Peterson, JCS 70 (2018) 37–51 (UET 6/1 61+503+691+701).
- **URLs:** https://oracc.museum.upenn.edu/epsd2/literary/Q000357 ; https://oracc.museum.upenn.edu/epsd2/literary/P346146 ; data from https://oracc.museum.upenn.edu/json/epsd2-literary.zip (copy in `../_bulk/`). JSON export timestamp 2022-12-07.
- **Retrieved:** 2026-10-16
- **Licence:** CC0 (stated inside each JSON file).

## Files
- `Q000357.cdl.json`, `P346146.cdl.json` — raw ORACC CDL JSON (from the zip, unchanged).
- `Q000357--oracc-web.html`, `P346146--oracc-web.html` — ORACC HTML text views (raw).
- `Q000357--composite-transliteration-lemmatised.md` — 89 lines; each line = label (`Seg.A, 1` …) + transliteration + `lem:` line with ePSD2 citation form[guide word]POS for every word (e.g. `amaru[flood]N`). Converted with `../../../tools/cdl2md.py`.
- `P346146--Ur-version-UET6-61+.md` — 32 lines of the Ur manuscript (obv. 1′–18′, rev. 1′–14′), unlemmatised. Content (per Peterson): appointment of the first king Alulim of Eridu as shepherd; animal/predator list "in those days there was no snake, no lion…" (cf. Enmerkar's "spell of Nudimmud"); "nam-lu₂-ulu₃(IRI)" spelling.

## Line numbering
Q000357: ETCSL segment + line (`Seg.C, 20` = ETCSL c174.C.20). P346146: tablet surface + primed line (`o 7'`, `r 2'`), no correlation to the composite given in ORACC — see Peterson 2018.

## Notes / caveats
- ORACC transliteration conventions: ŋ = ĝ; h (not ḫ); `{d}` determinatives; `⸢ ⸣` damaged; `[ ]` missing; `⟨ ⟩` omitted signs. A few qualifiers from ETCSL (e.g. `KUG?`) are dropped in the ORACC JSON.
- Composite text is identical in substance to ETCSL 1.7.4 — no MS 3026 (Schøyen) readings.

## Usefulness
Lemmatisation is the main gain (fast word-by-word glossing for a Hebrew translation). The Ur manuscript adds lines from the lost beginning; consult Peterson 2018 for interpretation.
