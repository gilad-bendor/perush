# ORACC epsd2/royal Q000947 – Laws of Ur-Namma (lemmatised, with ePSD2 morph)

- **What:** the ePSD2 "royal" corpus's composite of the Laws of Ur-Namma (Ur-Namma 20 = RIME 3/2.01.01.20, after Frayne 1997): the prologue (labels `Prolog 6` …), **laws §1–§11 with § labels** (`§1 1`, `§1 2` …, the numbering of Roth 1997 / Frayne), and fragments; 231 lines, each word lemmatised (ePSD2 citation form, guide word, POS) with the **morph** field (`{ba.i.n:~;rah₂}`) that decides the verbal prefix chain and aspect.
- **Source:** `../_bulk/epsd2-royal.zip` (downloaded 2026-10-18 from `https://oracc.museum.upenn.edu/json/epsd2-royal.zip`, 15 MB, gitignored), member `epsd2/royal/corpusjson/Q000947.json`; web https://oracc.museum.upenn.edu/epsd2/royal/Q000947 .
- **Licence:** CC0 (ORACC JSON data). Committed.
- **File:** `Q000947--lemmatised.md` (`tools/cdl2md.py --morph`).
- **Numbering:** older and shorter than the CDLI composite P432130 (Civil 2011 / Wilcke 2014), which is the base text; use this file for the lemmas and morph of the lines it shares, and for the **§1–§11 concordance** (its § labels).
- **Usefulness:** lexical help (rank 2) for `חוקים-ובריתות/6-חוקי-אור-נמה/`. The same zip holds the other Ur III and Isin royal inscriptions (Ur-Namma, Lipit-Eštar 01–10).
