## What it is / how to use it
An alphabetical index of about 5,000 Sumerograms (logograms) used in Akkadian texts, ordered by logogram. Each entry gives the Akkadian reading, a German gloss, and references to Borger's sign list (ZL/MZL), the CDA ("CD" + page) and CAD/AHw.
Use it when a transliteration has a logogram in capitals (e.g. `A.MA.RU` → *abūbu*, "flood"; `MU` → *šumu*/*zakāru*; `ESIR` → *kupru*) and you need its Akkadian reading.
- The same data is integrated into the eBL dictionary (`logograms` field) and the eBL sign pages (`/api/signs/<NAME>`, `logograms[]`). Those are easier to query by machine.
- **Caveat:** `pdftotext` drops the logogram column (special font). Only the Akkadian, the German gloss and the references survive. Read the page image to see the logograms.
