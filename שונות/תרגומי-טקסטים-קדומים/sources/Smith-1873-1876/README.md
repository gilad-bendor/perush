## Line numbering
Smith numbers lines by column (col. i 1–…, etc.), following the K 3375-based arrangement of his time. It does not map directly to modern numbering; align by content.

## Assessment
Of **historical interest only**: the first decipherment (1872). The names are early readings that are now obsolete: Izdubar = Gilgamesh, Hasisadra/Sisit = Ūta-napišti (Hasisadra = Atra-hasīs read backwards), Heabani = Enkidu, Nizir. It contains many misreadings. It is useful for the history of the Genesis–Babylon debate ("Babel und Bibel") but not for translation.
