## Assessment
**The only French item found, and of curiosity value only.** It is an 1890s Catholic popularisation with obsolete readings (Is-Tu-Bar/Izdubar, Samas-napistim, Bel for Enlil, Ninib, Amel-Ea for Ur-šanabi). For serious French comparison, see the paid editions recorded in `../_records-only--paid-and-restricted/README.md`: J. Bottéro, *L'Épopée de Gilgameš* (Gallimard 1992), and R. J. Tournay & A. Shaffer (Cerf 1994). E. Dhorme, *Choix de textes religieux assyro-babyloniens* (Paris 1907), has transliteration + French translation of the flood text and is on archive.org (https://archive.org/details/choixdetextesrel00dhoruoft). Dhorme died in 1966, so it is still in copyright in life+70 countries until 2036 (US: PD). It was **not downloaded**.
