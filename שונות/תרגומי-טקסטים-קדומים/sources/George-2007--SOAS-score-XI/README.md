# A. R. George, "SB Gilgamesh XI, score transliteration" (SOAS, 2007)

- **Editor:** Andrew R. George (SOAS, University of London)
- **What it is:** A synoptic ("score") transliteration of **every manuscript** of SB Tablet XI, line by line: Nineveh C, J, T, W; Assur b, c; Nimrud z; Babylon j; and catch-lines. These are the working scores behind George's *Babylonian Gilgamesh Epic* (OUP 2003). It contains **no translation**. It complements the eBL composite text, which is saved elsewhere and not touched here.

## Files
- `SB_XI_Score.pdf`: original PDF (Word → PDF, 13 Mar 2007).
- `SB_XI_Score.layout.txt`: `pdftotext -layout` extraction. **Warning:** George's custom transliteration font does not map to Unicode, so š/ṣ/ṭ/ḫ and determinatives come out garbled (e.g. `∞`=Š in logograms, `·`=š, `¿`=ḫ, `◊`=ṣ, `fl`=ṭ, `«…»`=half-brackets). Line numbers, sigla and column references are reliable. For readings, use the PDF.
- `eprints-soas-3349.raw.html`: the eprints record page (Wayback, Dec 2024).
- `soas-gilgamesh-standard-page-2016.raw.html`: SOAS "Standard Babylonian Gilgamesh" page that lists the 12 score PDFs (Wayback 2016).

## Line numbering
This is George's numbering (= BGE 2003 = eBL), lines 1–328 + catch-line. Landmarks used in the other READMEs: Puzur-[Enlil] 95; storm 6 days 7 nights 128; Nimuš 142–146; dove 148–149; Atra-hasis 197; "previously Ūta-napišti was a mortal" 203; "mouth of the rivers" 205–206.

## Assessment
This is the authoritative manuscript-level evidence: it shows which manuscript has which reading and where the composite is restored. It is essential for checking any doubtful reading in the eBL composite.
