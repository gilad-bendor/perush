# CDLI P480696 – Laws of Eshnunna, composite (RIME 4.05.19.add03), with the exemplars A, B, C

- **Text:** the Laws of Eshnunna (LE): a short date-and-occasion prologue (Daduša's accession) and laws §1–§60. Old Babylonian Akkadian (with many Sumerograms), Eshnunna, 19th c. BCE (Daduša, before Hammurabi's conquest of Eshnunna). Two main tablets from Tell Harmal (Šaduppûm): **A = IM 51059**, **B = IM 52614**; a small third piece **C** (CDLI ex. 03, P480695, §44–§47a).
- **Edition:** CDLI composite **P480696** = Q006412, "RIME 4.05.19.add03 (Laws of Eshnunna) composite" (CDLI cites RIME 4, 1990). Transliteration, a **normalization on every line** (`#tr.ts`) and an **English translation on every line** (`#tr.en`; translator not named). The standard modern editions (Goetze 1956; **Yaron 1988²**; Roth 1997) are not owned.
- **Exemplars:** **P480693** (ex. 01 = A, IM 51059, 441 ATF lines), **P480694** (ex. 02 = B, IM 52614), **P480695** (ex. 03 = C); their ATF is embedded in the composite's JSON export and saved here. Every exemplar line carries a link `>>Q006412 NNN` to its composite line, so the alignment is exact (`laws_config.py`). One link is wrong in CDLI: A obv. ii 13.b (= composite 70, §21) is linked to "07".
- **URLs:** https://cdli.earth/artifacts/480696 · JSON export `https://cdli.earth/artifacts/480696/json` (`[0]['inscription']['atf']`; witnesses `[0]['witnesses'][i]['witness']['inscription']['atf']`); also /artifacts/480693/json, /480694/json.

## Notes on the composite (found while preparing the data, 2026-10-18)
- The CDLI normalization has slips (as in LH): e.g. 4–5 (the Sumerian prologue is "normalized" as *uṣima … ibūrma*); 67 *uštepil* for the written *i-te-pu!-usz*; 181 (§57) the composite and A write *ik-ki-im-ma* "gored" for the dog's bite (a scribal slip carried from §55), while `ts` silently reads *iššukma*. Translate the transliteration and note the difference.
