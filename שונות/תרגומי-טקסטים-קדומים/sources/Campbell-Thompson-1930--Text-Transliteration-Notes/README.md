## Line numbering
This is Thompson's numbering, also used in his 1928 translation and largely by Heidel. See `../Campbell-Thompson-1928/README.md` for how it maps to George. Thompson's Tablet XI runs to ~307 lines + catch-line. George's runs to 328 + catch-line, because George adds Assur, Babylon and Nimrud manuscripts and divides some lines differently.

## Assessment
This was the standard text edition for 70 years (it superseded Haupt) and was replaced by George 2003. Its plates and readings are useful as a historical check on readings George discusses ("Thompson read …"). Do not use it as the base text. Use the PDF page images, not the OCR.
