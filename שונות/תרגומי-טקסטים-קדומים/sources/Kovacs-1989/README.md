## Line numbering
The online text has **no line numbers**. Kovacs's verse lines are close to one-to-one with the Akkadian lines of Thompson's numbering, which is behind George by up to ~10 lines in the 190s–200s. Livius.org reproduces this translation with line markers `[11.n]`, so use `../Livius/tablet-XI.md` to locate lines.

## Assessment
A clear, sober, literal-leaning modern prose-verse translation, the standard US classroom translation before George 1999. It predates George's critical edition, so it has older restorations, older name forms (Utanapishtim, Shuruppak, Ubartutu, Mt. Nimush/Nisir) and gaps that are now filled. It is useful as a plain-English comparison but is superseded by George 1999/2003/eBL.
