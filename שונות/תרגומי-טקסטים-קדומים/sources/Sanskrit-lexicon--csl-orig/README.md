# The Cologne Digital Sanskrit Lexicon, source files (csl-orig)

- **What:** the digitized source files of **Monier-Williams** (1899, `mw.txt`) and **Grassmann**, *Wörterbuch zum
  Rig-Veda* (1873, `gra.txt`, with every Rigveda attestation by Grassmann's own hymn numbers).
- **URLs:** https://raw.githubusercontent.com/sanskrit-lexicon/csl-orig/master/v02/mw/mw.txt ; …/v02/gra/gra.txt
  (the www.sanskrit-lexicon.uni-koeln.de site answers 403 to scripts; the GitHub source works).
- **Retrieved:** 2026-10-30 (Round 5 run 1).
- **Licence:** the dictionaries are public domain; the digitization's licence was not checked → **git-ignored**, consulted
  per word (`../../הוודה-והאווסטה/vedic_tools.py mw / gra <word>`, keyed by SLP1 transliteration).
- **Usefulness:** high (Grassmann for the RV, MW for the Brāhmaṇas and the epic).
