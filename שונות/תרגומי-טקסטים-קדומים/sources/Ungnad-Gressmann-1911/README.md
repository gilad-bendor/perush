## Line numbering
Ungnad follows Haupt's numbering, which is close to Thompson's (see `../Heidel-1946/README.md` for the offset against George: ~+2 by the dove scene, ~+10 by l. 195).

## Assessment
This was the standard German translation before 1930 and is historically important for us: **Ungnad's translation (via G. E. Burckhardt's 1916 retelling, which was based on it) is the likely German source of Tchernichovsky's 1924 Hebrew version** (Simchoni's introduction names Jensen and Ungnad as the translations). It has old readings: Ninib = Ninurta, Ubara-Tutu, Nisir, "Zyklon" for abūbu, and Ut-napištim. It is philologically obsolete but useful for tracing where Tchernichovsky's wording comes from.
