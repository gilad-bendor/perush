## Line numbering
ETCSL composite line numbers (= ORACC). For the proverbs, the ETCSL TEI also numbers each proverb (`<lg n="1.9">`, line ids `c6101.A.1.9.10` = proverb 1.9, line 10); the ETCSL translation is one paragraph per proverb. Our files keep both: the line number as the entry label, the proverb number as the unit.
