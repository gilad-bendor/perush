## Assessment
**Very valuable for this project.** It is a careful, literal translation made for the Chicago Assyrian Dictionary files, with parentheses marking explanatory additions, square brackets marking restorations, and "(?)" marking uncertain readings. It is also the classic, conservative comparison with Genesis. Outdated in: pre-1950 readings (Nisir for Nimuš, Puzur-Amurri, "Irragal"), no Assur, Babylon or Nimrud manuscripts, and older views on Atrahasis (before Lambert–Millard 1969). Register: mid-20th-c. scholarly English with "thou/thee" for speech.
