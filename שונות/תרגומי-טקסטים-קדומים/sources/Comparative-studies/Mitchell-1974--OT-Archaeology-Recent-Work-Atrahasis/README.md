# Mitchell 1974 — "Old Testament Archaeology: Some Recent Work" (Atrahasis section)

- **Citation:** T. C. Mitchell, "Old Testament Archaeology: Some Recent Work," *Faith and Thought* 101/2 (1974): 142–158 (a paper read to the Victoria Institute, 2 Feb 1974).
- **URL:** https://gospelstudies.org.uk/biblicalstudies/pdf/ft/101-2_142.pdf (biblicalstudies.org.uk mirror)
- **Retrieved:** 2026-10-16
- **Access basis:** Free on biblicalstudies.org.uk / gospelstudies.org.uk, with permission of the Victoria Institute.

**Relevance:** The opening section (Atrahasis) is a short survey by a British Museum curator. It covers the Atrahasis epic, its plague → famine → drought → flood structure, the seven-day warning, and its relation to Gilgamesh XI, which Mitchell judges to be "largely the source" of Gilgamesh XI, and to Genesis. Only the first pages are relevant.
