## Contents and relevance to Tablet XI
This book edits the **Old Babylonian** Pennsylvania and Yale tablets (= SB Tablets I–II, III–IV), not Tablet XI, so it contains **no Tablet XI text**. The introduction touches on the Flood story: the name Atra-hasis for the flood hero, the date of the deluge fragment, the "lesson" attached to the deluge story in the Assyrian version, and Sumerian vs. Akkadian deluge tales. It is useful only as background on the epic's growth.
