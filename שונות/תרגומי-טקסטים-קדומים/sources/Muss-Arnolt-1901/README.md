Muss-Arnolt uses Haupt's numbering (like Jensen and Ungnad); see the Heidel README for the offsets against George.

## Assessment
A competent American translation c. 1900 (based on Haupt and Jensen) with a useful bibliography of 19th-century flood translations. It is obsolete philologically (Nimrod-epic, Ṣît-napištim, Ninib, Nisir) and of historical value only.
