# Renderings: the other Akkadian flood versions (project glossary)

The shared `../renderings.md` binds; this file extends it with words that occur in these texts and not (or not in this sense) in the shared file. Words already fixed by Gilg. XI (`../2-גילגמש-XI--סיפור-המבול/renderings.md`) or by Atra-ḫasīs (`../1-אתרחסיס/renderings.md`) are followed and listed here only when the choice matters for these texts.
Format (guidelines §6.6): Akkadian | Hebrew | rejected | reason / tag | lines.
