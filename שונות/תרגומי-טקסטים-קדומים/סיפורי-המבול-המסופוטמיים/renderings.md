# Shared renderings: the Mesopotamian flood corpus

Binding for all six projects in this folder. See `corpus.md` for the editing rule: project translators propose additions in their `project.md`, and the corpus coordinator merges them here.

Echo tags follow guidelines §6.4: [cognate], [equivalent], [divergence], [absent].
"Seed" entries were set before drafting (2026-10-16). Change one only with a note in the Changelog below, and then update every project that uses it.

| *uqur bīta bini eleppa* (Gilg.) / *ubut bīta bini eleppa* (OB, Ark 4) | נְתֹץ בַּיִת, בְּנֵה סְפִינָה / הֲרֹס בַּיִת, בְּנֵה סְפִינָה | *naqāru* = נתץ; *abātu* = הרס. | *makkūra zēr-ma napišta bulliṭ* | מְאַס בִּרְכוּשׁ וְהַחֲיֵה נֶפֶשׁ | *bulluṭu* ↔ `לְהַחֲיֹת` (בראשית ו:יט–כ; ז:ג) [equivalent]. *napištu* ↔ `נֶפֶשׁ` [cognate]. |

| *ilū kīma zubbī / zumbī eli bēl niqê ipteḫrū* | הָאֵלִים הִתְקַבְּצוּ כִּזְבוּבִים עַל בַּעַל הַזֶּבַח | *zubbu* ↔ `זְבוּב` [cognate]. |
| *šīmtu* | גּוֹרָל | "Fate, what is decreed". *šīmat awīlūti* = גּוֹרַל הָאָדָם. |

## 4. Register reminders specific to the corpus
- Sumerian and Greek texts use the same Hebrew for the same concept: the Sumerian *a-ma-ru* = `מַבּוּל`, the boat = `סְפִינָה`, and so on. Berossus's Greek πλοῖον = `סְפִינָה`, while σκάφος and λάρναξ get their own rendering with a note.
- **Speech:** the gods' speech is formal and short, so keep it so. Don't add emotion words that aren't in the Akkadian.
