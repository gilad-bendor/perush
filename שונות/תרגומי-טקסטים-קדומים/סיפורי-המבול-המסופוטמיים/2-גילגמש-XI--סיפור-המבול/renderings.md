# Renderings: Gilgameš XI 1–208 (project glossary)

This file lists the recurring words of Gilg. XI that are **not** in the shared `../renderings.md`. The shared file binds; this one extends it.
Format (guidelines §6.6): Akkadian lemma (eBL) | chosen Hebrew | rejected | reason | lines. Echo tags per guidelines §6.4.

Because Atra-ḫasīs III and the other Akkadian versions will copy this Hebrew for shared lines, entries marked **(corpus)** are proposed for the shared file too (see `project.md`, "Proposals for the shared renderings").
