# Renderings: Esarhaddon's Succession Treaty (EST), project 1 of `חוקים-ובריתות/`

The corpus file `../renderings.md` is binding (it holds *adê*, *māmītu*, *tamītu*, *naṣāru*, *šemû*, *râmu*, the oath grammar and the curse vocabulary). This file holds the EST formulas, fixed **before drafting** by the coordinator (2026-10-17). Every recurrence must match **letter for letter** in the unvocalized `>` lines (the verification script strips niqqud and compares). Vocalize names and ambiguous words at their first occurrence in each annotated file only.

Columns: Akkadian (SAAo normalization) | Hebrew, plain spelling (as it must appear) | echo | note.
